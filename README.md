## 🌸 About This Project

This is a school geography project reimagined as a **Y2K MySpace profile** —  
Juicy Couture tracksuits, glitter GIFs, sparkly dividers, and pink everything.

Each geography theme gets its own page, styled like a retro MySpace “About Me” section.

♡ Pink heart cursor
♡ Glitter trail cursor
♡ Floating sparkles
♡ Autoplay MySpace music
♡ Charm bracelet navigation
♡ Fake comment wall
♡ Full Juicy Couture Y2K aesthetic
♡ Hosted on GitHub Pages
